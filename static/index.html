Frequently asked questions

Everything you need to know about Detecto, zero-day threat detection, machine learning, and academic project background—in simple English.

?
What is Detecto and how does it protect me from dangerous links? +

Detecto is an AI-powered cybersecurity scanner that checks whether a website link (URL) is safe, suspicious, or malicious before you click it.

Traditional security tools rely on "blacklists" of already-known bad links. The problem? Cybercriminals create millions of temporary phishing links that vanish within hours—long before blacklists update. Detecto inspects the mathematical DNA and network behavior of the link in milliseconds to block brand-new (zero-day) scams on the spot.

How does Detecto check a link in milliseconds without freezing? +

Standard Windows DNS lookups can freeze for 5 to 10 seconds if a domain doesn't exist (due to operating system NetBIOS/LLMNR timeouts).

Detecto bypasses slow OS lookups by sending direct, lightweight UDP queries to fast public DNS resolvers (Cloudflare 1.1.1.1 and Google 8.8.8.8). This returns a real DNS answer in just 45 milliseconds and never freezes your browser.

What are the 27 "features" extracted from a URL? +

Features are 27 structural and linguistic clues calculated directly from the URL string. They include:

• Length & Depth: Total character length, hostname length, path depth, and number of subdomains.
• Symbol Counters: Counts of hyphens, dots, underscores, question marks, and @ credential trick symbols.
• Digit Ratios: The percentage of numbers versus letters (phishing links often use long random number sequences).
• Shannon Entropy: A mathematical formula measuring character randomness.
• Suspicious Keywords: Matches for sensitive terms like login, verify, banking, secure, and wallet.

What is Shannon Entropy and why does randomness indicate a threat? +

Think of entropy as a "scramble meter."

Legitimate organizations select memorable, human-readable names like google.com or wikipedia.org which have low randomness. In contrast, automated phishing kits and malware command-and-control servers generate scrambled strings like a7x9q-sec-auth.xyz. A high entropy score immediately alerts Detecto to possible automated threat behavior.

How does Detecto catch brand typosquatting (e.g. paypa1.xyz or apple-verify.com)? +

Detecto maintains a database of 20+ protected brands (PayPal, Apple, Google, Microsoft, Netflix, Steam, Amazon, etc.).

When you scan a domain, Detecto runs Levenshtein Edit Distance (counting letter additions, deletions, or swaps) and Homoglyph Detection (detecting numbers like 1 instead of l, or 0 instead of o). If an unrecognized site closely mimics a famous brand, Detecto flags it as an impersonation attack.

Which Machine Learning algorithm is used and what is its accuracy? +

Detecto uses the Random Forest Classifier with 100 decision trees, trained on a balanced dataset of 30,000 real-world benign and malicious URLs.

Random Forest was selected because it achieves 99.4% accuracy, prevents overfitting, handles both numbers and boolean indicators naturally, and produces calibrated prediction probabilities in less than 3 milliseconds.

What do the three Verdict tiers (Safe, Suspicious, Malicious) mean? +

• 🛡️ Verified Safe (0% – 25% Risk): Normal lexical structure, legitimate DNS resolution, trusted SSL encryption, and authentic domain authority.
• ⚠️ Suspicious (26% – 65% Risk): Displays warning indicators like high character entropy, high-abuse domain extensions (.xyz, .top), missing HTTPS, or redirect hops. Proceed cautiously.
• 🚨 Malicious Threat (66% – 100% Risk): High probability of brand phishing, credential theft, raw IP hosting, or malware distribution. Do not open or enter credentials.

What does Detecto inspect in a website's HTML code? +

When "Live Network Inspection" is enabled, Detecto streams just the first 35KB of HTML from the target server without executing dangerous JavaScript.

It checks whether the page contains an <input type="password"> field and compares the page title against the domain. If an unrecognized or typosquatted website contains a login password box, Detecto flags it as a credential-harvesting trap.

How does Detecto unwrap shortened URLs like bit.ly or tinyurl? +

URL shorteners are commonly used by attackers to hide malicious links. Detecto follows HTTP 301 and 302 redirect headers across the network to uncover the true final destination domain without executing browser scripts. Both the shortener and the final URL are then checked.

Is my scan data kept completely private? +

Yes, 100% private. Detecto is built with privacy-first principles. All machine learning inference runs locally on your system, and scan audit logs are stored in your local SQLite database (data/detecto.db). No browsing data or URL history is ever sent to third parties or tracking servers.
